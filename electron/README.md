# Electron process code

`main.cts` creates the secure native window and owns fixed IPC handlers, including `echo-report:export-pdf` which opens the native Save As dialog and invokes `webContents.printToPDF()` for A4 portrait output. `preload.cts` contains the narrow renderer bridge. `pdf.cts` owns readiness checks, filename sanitization, local PDF writing, and best-effort opening with the default PDF application. `transcription.cts` validates the WAV the renderer produced (16 kHz mono PCM 16-bit; no ffmpeg is shipped) and owns temporary files and the fixed whisper.cpp process invocation. They compile to CommonJS (`.cjs`) because Electron's main and sandboxed preload processes require that runtime format here. See the root README for setup and commands.
